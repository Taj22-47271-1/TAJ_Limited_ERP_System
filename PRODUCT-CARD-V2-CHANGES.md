# Product Card V2 changes

- Customer dashboard product section now uses larger image cards.
- Shop page product cards now use the same premium hover interaction.
- Added hover lift, shine sweep, glow, stock badge, image zoom, title/price accent, and cart-button pulse.
- Product images use `object-fit: contain` so uploaded product photos are not cropped.
- Dashboard product panel is wider and uses 3 cards per row on large screens.
- Shop cards use larger 225px product images on desktop.
- Product detail image increased to 520px and gets a soft zoom on hover.
- Responsive layouts added for tablet/mobile.
- Reduced-motion accessibility support added.
